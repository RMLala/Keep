    Protection de vos données

    Sauvegardes

    Créez une copie chiffrée sur votre appareil ou dans votre espace privé Google Drive.

    Les sauvegardes sont chiffrées. Leur restauration nécessite le PIN du coffre ou la clé de secours. Aucun fichier n’est envoyé à Drive sans votre action.

    Copie locale

    Choisissez le dossier Download/backup dans la fenêtre de sélection lorsque votre navigateur le permet. Sinon, le fichier sera téléchargé dans son dossier habituel.

    Restaurer

    Sauvegarde vers Google Drive

    Passkeep chiffre le fichier avant le partage. Sur Android, choisissez Google Drive dans la feuille de partage. Pour restaurer, sélectionnez le fichier Drive avec le sélecteur de sauvegarde ci-dessous. Aucun compte Google ni accès OAuth n’est demandé dans Passkeep.

    Aucun fichier n’est partagé avant votre action.
    Accès au coffre

    Sécurité PIN

    Utilisez le PIN Passkeep et, dans l’APK, activez la biométrie de l’appareil.

    Biométrie Android

    L’APK peut demander l’empreinte ou la reconnaissance biométrique, avec le verrouillage système comme solution de secours lorsque l’appareil le permet.

    La version HTML autonome ne peut pas ouvrir le capteur Android.

    Changer le PIN

    Clé de secours

    La clé de secours permet de réinitialiser le PIN. Renouveler la clé invalide immédiatement la précédente.

    Service central configuré : appforge-license-api.lalainaadclick.workers.dev. Aucun réglage réseau n’est nécessaire.

    Guide rapide et FAQ

    Comment protéger mon coffre ?

    Choisissez un PIN robuste, activez la biométrie dans l’APK et conservez la clé de secours séparément. L’application HTML utilise le PIN.

    Comment enregistrer une sauvegarde dans Drive ?

    Créez une sauvegarde chiffrée puis choisissez Google Drive dans le menu de partage Android. Pour restaurer, choisissez le fichier dans le sélecteur Android.

    Passkeep peut-il récupérer mon PIN par e-mail ?

    Non. Passkeep ne transmet ni le PIN ni le contenu du coffre au support. Utilisez votre clé de secours pour récupérer l’accès.

    Signaler une anomalie

    Le diagnostic proposé exclut les mots de passe, les notes du coffre, le PIN, les clés de licence et les jetons cloud. Rien n’est envoyé sans votre confirmation et l’ouverture de votre application e-mail.

    Confidentialité et conditions

    Les données du coffre sont chiffrées localement. Les exports Excel sont en clair : protégez-les et supprimez-les après usage. La synchronisation transmet uniquement le snapshot chiffré.

    Les conditions d’utilisation figurent dans LICENCE.md. Les mentions légales de l’éditeur doivent être complétées avant commercialisation.
